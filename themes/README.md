# Eigene Tagore-Themes

Neue Themes werden hier mit dem Skill `create-wordpress-extension` angelegt.
Theme-Slugs folgen `flz-<name>`. Installierte Fremdthemes und Kopien in den
WordPress-Laufzeitverzeichnissen sind keine bearbeitbaren Quellen.

Jedes Theme erhält eine eigene `AGENTS.md`, eine kurze `README.md`, passende
Tests sowie einen Symlink nach `../tagore-local/public/wp-content/themes/`.
